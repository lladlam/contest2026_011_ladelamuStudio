# 稳定性与性能压力测试
## 最低压力场景

1. 连续运行 8 小时，保持以太网和米家增量同步。
2. 家庭与房间往返 1000 次。
3. 房间列表与设备详情往返 1000 次。
4. 操作传感器详情、灯开关和亮度滑块；网络断开/恢复 20 次。
5. 每 30 分钟记录任务状态、动态内存、网络状态和 UI 响应。

若固件提供 `ps`、`free`、栈着色或等效诊断命令，记录每个关键任务的最低栈
余量以及测试开始/结束的内存值。若没有这些能力，在结果中明确写“未启用”，并
单独建立配置补强项。

## 通过条件

- 无 panic、RISC-V exception、assert、watchdog reset 和任务意外退出。
- 页面和触摸始终可用，切换计数全部完成。
- 动态内存没有随循环持续下降；关键任务栈保留合理余量。
- 米家全量快照只用于初始化或版本断档，普通状态变化使用增量更新。
- 保存 8 小时串口日志、计数记录、内存趋势和关键操作视频。
