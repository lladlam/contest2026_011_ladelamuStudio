# 登录持久化测试
## 步骤

1. 使用米家 App 完成一次扫码登录，确认家庭和设备同步。
2. 完全断电 10 秒后上电，重复 10 次。
3. 每次确认日志包含 persisted session restored，且无需重新扫码。
4. 使用正常升级镜像重新烧录系统、字体和 data 分区，再检查会话恢复。
5. 单独执行明确会擦除 `userid` 的全片擦除，确认系统回到待登录状态。

## 预期

- 正常重启和正常升级不会清除 `userid` 中的冗余持久化记录。
- 记录损坏或全片擦除时安全退回登录流程，不泄露口令、不崩溃。
- 证据中必须遮盖服务令牌、保险箱口令、Cookie 和二维码会话参数。
